## 📁 How It Works — Troubleshooting Workflow

1. Confirm the game build and check which upscaling or frame-generation options are actually offered on your hardware.
2. Establish a baseline at native rendering or a standard preset, then note average frame rate and responsiveness.
3. Enable one supported upscaling option and repeat the same location or scene.
4. If the game offers frame generation, compare on/off behavior, looking for flicker, pacing or input-response differences.
5. Update the graphics driver from the hardware vendor if an incompatibility is documented.
6. Keep the configuration that works reliably and report reproducible graphics issues to the developer.
